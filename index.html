Blood Group Detection Using Fingerprint Images

GitHub Repository

  • Built and trained deep learning models including LeNet, AlexNet, VGG16, and ResNet34.
  • Compared overall model performance using accuracy/loss curves and comprehensive evaluation metrics across multiple epoch configurations to identify ResNet as the optimal architecture.
